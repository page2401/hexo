05. 高阶代码块与语法高亮（Hexo {% codeblock %} + 服务端 highlight.js）

技术文档中超过 40% 的篇幅由代码块构成，但标准 CommonMark / GitHub Flavored Markdown 仅定义了围栏语言标识（```ts）**，并未定义文件名标题栏、指定行高亮、带语法着色的行级 Diff 以及多语言 Tab 代码组。本文件由标准 GFM 母版派生适配至 **Hexo (hexo@8.1.2 + hexo-util 服务端 highlight.js)。

1. 代码块文件名标题栏与基础语法高亮（内置 {% codeblock %}）

早在现代前端文档框架发明 title="..." 之前，Hexo 便从 Octopress 继承并内置了经典的 {% codeblock [title] [lang:language] [line_number:true] [mark:1,3-5] %} 标签插件（其实反引号围栏底层 backtick_code_block 过滤器同样支持在语言名后直接追加空格分隔标题与 mark: 键值对！）：

  • 构建期调用 hexo-util 封装的 highlight.js 在 Node.js 端直出 <figure class="highlight ts"><figcaption><span>...</span></figcaption>...</figure>，页面保持 0 KB 客户端 JS。
  • 重要边界：与三反引号围栏不同，成对标签 {% codeblock %} 先经过 Nunjucks 解析——若代码体内部含有字面量 {{ ... }} 或 {% ... %}，外层反倒不如直接使用 Hexo 增强版反引号围栏安全！

2. 关键行聚焦与高亮（mark:3,7-9 区间标记）
